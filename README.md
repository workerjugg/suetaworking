# FreeVPN Guardian

Бесплатная автоматическая платформа: собирает публичные прокси/VPN-конфигурации, проверяет, ранжирует и публикует подписки на GitHub Pages. **Ваш компьютер для работы не нужен** — всё крутится в GitHub Actions по расписанию (каждые 6 часов). Бюджет 0 ₽, карта не нужна.

> ⚠️ Публичные узлы принадлежат неизвестным людям: владелец может видеть и подменять трафик. Не используйте их для банков, почты и важных аккаунтов. Анонимность не гарантируется.

## Как это работает

`источники → парсинг → проверка синтаксиса/безопасности → дедупликация → TCP-проверка → sing-box-тест (до 300 лучших) → геолокация → история и рейтинг → профили → подписки + dashboard → GitHub Pages`.

Если новый запуск не нашёл рабочих серверов (`min_alive`), **публикация не происходит** и остаётся прошлая рабочая подписка. Состояние (`subscriptions`, `data`) хранится в кеше Actions между запусками.

Проверка идёт с раннера GitHub (США), а не из Самары. Задержка и скорость там могут сильно отличаться от ваших — для этого есть локальный оптимизатор.

## Установка (один раз, ~10 минут)

1. Создайте на GitHub **публичный** репозиторий (Pages на бесплатном тарифе требует публичный) и загрузите все файлы проекта.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. **Actions → collect-and-publish → Run workflow.** Первый запуск занимает до 45 минут. В конце появится ссылка на сайт.
4. Подписки: `https://<логин>.github.io/<репозиторий>/subscriptions/best` (аналогично `all`, `low-ping`, `europe`, `happ`, `incy`, `singbox` и т.д.). Все ссылки видны на главной странице сайта.
5. Telegram (по желанию): Settings → Secrets and variables → Actions → добавьте `TG_BOT_TOKEN` и `TG_CHAT_ID`. Без них всё работает, о сбоях вам напишет GitHub на почту.

Публичный репозиторий и подписки видны всем. Секретов в них нет: `servers.json` не содержит UUID, паролей и ключей, но сами подписки, конечно, содержат ссылки на серверы.

## Источники

Файл `config/sources.json`. Добавить источник — новый блок `{"name", "type": "url", "location": "https://…", "trusted": false, "enabled": true}`; ядро менять не нужно. `trusted: true` ставьте только для серверов, которым вы доверяете сами.

Подключено **11 включённых источников** (адреса взяты со страниц репозиториев; живость из моей среды проверить не удалось, это проверит первый запуск, статус каждого виден в dashboard):

| Источник | Что даёт | Лицензия репозитория |
|---|---|---|
| igareck/vpn-configs-for-russia (3 файла WHITE-* / Vless-Reality-White-Lists) | обход **белых списков** мобильного интернета РФ | GPL-3.0 |
| igareck (BLACK_VLESS_RUS, BLACK_VLESS_RUS_mobile, BLACK_SS+All_RUS) | обход обычных блокировок в РФ | GPL-3.0 |
| whoahaow/rjsxrd (bypass-all, default/all-secure) | secure-конфиги для SNI/CIDR и обычных блокировок, ежечасно | MIT |
| barry-far/V2ray-Config | большой агрегатор, каждые 15 минут | MIT |
| Epodonios/v2ray-configs | агрегатор, каждые 5 минут | в README MIT, в боковой панели GPL-3.0 (противоречие) |
| 735754647/Free-Nodes, ninjastrikers/Nexus-nodes | агрегаторы | MIT |

Выключены (включайте сознательно): kort0881 (противоречивая лицензия с запретами), nodesradar (лицензия не указана).

**Профиль `whitelist`** (`…/subscriptions/whitelist`) собирает узлы из источников с тегом `whitelist`. Важно: проверить обход белых списков с раннера GitHub нельзя, он не в мобильной сети РФ. Поэтому для этого профиля достаточно открытого TCP-порта; тест через туннель с раннера такие узлы не отсекает. Работает ли конкретный узел у вас на МегаФоне, покажет только проверка на вашем телефоне или оптимизатор `local/optimizer.py` с мобильным интернетом.

Объём: за запуск проверяется до 4000 узлов (приоритет у whitelist и найденных в нескольких источниках), остальные в этот раз пропускаются (`not_probed` в статистике) и попадут в выборку в следующие запуски.

Проверьте условия использования и лицензии источников сами. Если источник недоступен, остальные продолжают работать.

## iPhone

1. Установите Happ или Incy из App Store (на них ориентирован проект).
2. Скопируйте ссылку: для Happ — `…/subscriptions/happ`, для Incy — `…/subscriptions/incy`.
3. Добавьте как подписку по ссылке; включите автообновление в настройках приложения (Incy сам читает интервал 6 часов из тела подписки по документации).
4. Для автоподбора по задержке удобнее sing-box-клиент и профиль `singbox` (`urltest`). Системного kill switch на iPhone нет — не рассчитывайте на него.

Статус совместимости честный: формат Happ и Incy соответствует их документации, но **в самих приложениях я это не проверял**. Если импорт не пойдёт — пришлите текст ошибки, поправим.

## Windows

1. Подписка: v2rayN → `…/subscriptions/v2rayn`, Hiddify → `…/subscriptions/hiddify`.
2. **Локальный оптимизатор** (по желанию, запускать вручную, ПК не обязан работать постоянно): установите Python 3.12+, откройте `local\run_optimizer.bat`, подставьте свою ссылку `…/subscriptions/all`. Он измерит серверы из вашей сети (МегаФон при раздаче с телефона) и создаст `local\out\local_ranking.json` и `local_best`. Ничего никуда не отправляется, телеметрии нет.
3. **Kill Switch** (по желанию, от администратора): `local\killswitch.ps1 -Apply -ServerIPs …` — спросит подтверждение, снимается `-Remove`. Блокирует весь исходящий трафик, кроме указанных IP, LAN и loopback. При смене сервера IP нужно добавить в список.

## Измерения из Самары через МегаФон

Глобальные замеры идут с раннера GitHub. Локальные — только оптимизатором (на Windows) либо самим клиентом на телефоне (`urltest` в профиле sing-box проверяет серверы с устройства). Результаты в публичный репозиторий не отправляются.

## Расписание и настройки

- Расписание: `.github/workflows/collect.yml`, строка `cron` (по умолчанию каждые 6 часов). Реже — экономнее лимиты Actions.
- Лимиты и размеры: `config/sources.json` → `limits`, `tunnel`.
- `healthcheck.yml` раз в сутки проверяет, что подписка свежая (< 30 ч) и серверов ≥ 5; иначе падает и GitHub шлёт письмо.

## Типичные проблемы

- **Страница сайта пустая / 404** — не включён Pages (шаг 2) или не завершился первый запуск.
- **«Данных пока нет»** — первый запуск не опубликовал ничего (источники недоступны или рабочих < 5). Смотрите лог шага «Collect» и `stats.json`.
- **В `check_level` написано tcp_connect** — sing-box не установился; открытый порт ≠ рабочий прокси.
- **Мало серверов** — публичные списки быстро умирают; добавьте источники.

## Обновление проекта

Замените файлы в репозитории новой версией; кеш состояния подхватится сам.

## Известные ограничения

- GitHub Actions не VPN-сервер; он только собирает и проверяет. Лимиты бесплатных минут у приватных репозиториев ниже, у публичных — щедрее.
- Публичный репозиторий со списками прокси может нарушать правила платформы или условия источников. Проверьте их; ответственность на владельце репозитория.
- Нет вечной гарантии: бесплатные узлы умирают, GitHub меняет лимиты.
- Скорость измеряется с раннера, а не у вас.
- Файлы лицензии (`LICENSE`) не добавлены — выберите сами.
